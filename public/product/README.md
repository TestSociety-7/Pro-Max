# Product photos

All photos are the owner's own Pro Max images, resized to WebP.

| Slug | Used for | Files |
| --- | --- | --- |
| `duo` | Opening scene + order summary thumbnail (black and beige side by side, cropped from the English poster) | `duo-480.webp`, `duo-788.webp` |
| `black` | Color showcase, black | `black-480/800/1122.webp` |
| `beige` | Color showcase, beige | `beige-480/800/1122.webp` |
| `poster-ar` | Full Arabic poster section | `poster-ar-480/800/1122.webp` |
| `poster-en` | Spare (English poster); `/og.jpg` social preview is cropped from it | `poster-en-480/800/1122.webp` |

To replace a photo keep the same file names and aspect ratio, or update the sizes in `src/app/(store)/ProductPicture.tsx`.
